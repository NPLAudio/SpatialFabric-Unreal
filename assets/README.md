# Unified branding

- `logo.png`: original SpatialFabric artwork from this repository (legacy JPEG payload).
- `audioloom-source.jpg`: original AudioLoom artwork from its `Resources/EditorStyles/Icon128.png` (JPEG payload), retained with AudioLoom's MIT attribution in `ThirdParty/AudioLoom/LICENSE`.
- `spatialfabric-mark.png`: composite of both original colored marks, with the legacy wordmarks removed.
- `spatialfabric-unified.png`: unified SpatialFabric documentation banner, incorporating both original marks and an AudioLoom credit.
- `../Resources/Icon128.png`: real 128×128 PNG plugin icon derived from the combined mark.

Reproduce with `python Tools/build_branding.py` (Pillow 12+, and installed Segoe UI or DejaVu Sans). No font files are redistributed.
